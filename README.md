# Loan Approval Prediction System

## 📋 Project Overview
This is an **Intro to Data Science** project that predicts loan application approval using **Logistic Regression**. The project demonstrates complete data science workflow: data preprocessing, cleaning, exploratory analysis, and predictive modeling.

## 📊 Dataset
- **Source**: Kaggle Loan Dataset
- **Records**: 44,000+ loan applications
- **Features**: Income, Credit Score, Loan Amount, Employment Years, etc.
- **Target Variable**: Loan Approval (Binary Classification)

## 🔧 Methodology

### 1. Data Exploration & Analysis
- Five-number summary (Min, Q1, Median, Q3, Max)
- Mean, Mode, Median calculations
- Distribution analysis using visualizations
- Outlier detection

### 2. Data Cleaning & Preprocessing
- Outlier removal using statistical methods
- Missing value handling
- Data normalization using:
  - Min-Max Scaling
  - Log Transformation
  - Z-score Normalization

### 3. Exploratory Data Analysis (EDA)
- Visualization of feature distributions
- Data balancing check
- Feature correlation analysis

### 4. Model Training
- **Primary Model**: Logistic Regression
- **Algorithm**: Binary Classification
- **Challenge**: Imbalanced dataset (95% approved cases)
- **Solution**: Weighted classification with custom boundary tuning

### 5. Model Evaluation
- Accuracy, Precision, Recall metrics
- Classification threshold optimization
- Real-time prediction testing

## 🎯 Key Findings
- Successfully identified loan approval patterns
- Handled class imbalance by adjusting classification boundaries
- Model accurately predicts approval decisions despite imbalanced data
- 95% of applicants in dataset are approved cases

## 💻 Technologies Used
- **Language**: R Programming
- **Libraries**: ggplot2, caret, dplyr
- **Tools**: RStudio
- **Concepts**: Statistical Analysis, Machine Learning, Data Visualization
